# Release checklist: cobalt 0.1.0-alpha

The goal: a **feature complete alpha for COBOL-85** on Linux and Windows
(x86-64), with its strictness levels, diagnostics and documentation. An item
is done when its "Done when" holds; tick it in the same commit.

Status as of 2026-11-11: NIST CCVS85 passes on NC, SM, SQ, RL, IX, ST, IC,
IF, SG, DB and RW with no failures (IX110A and ST301M excluded, see 1.6); CM
is not supported (1.3).

## 1. Language (COBOL-85)

- [x] **1.1 Report Writer (RW module).** RD entries (CONTROL, PAGE with
  HEADING, FIRST / LAST DETAIL, FOOTING), report groups of every TYPE, LINE,
  NEXT GROUP, COLUMN, SOURCE, VALUE, SUM with UPON and RESET (sum counters
  rolled into higher ones), GROUP INDICATE, INITIATE, GENERATE (detail and
  summary), TERMINATE, USE BEFORE REPORTING, SUPPRESS PRINTING,
  PAGE-COUNTER, LINE-COUNTER. The NIST RW programs pass (43 tests);
  `tests/report_writer`, `tests/report_summary`, `tests/diag/report*`;
  `runtime/ABI.md` section 16.
- [x] **1.2 Debug module (DB).** The 6 failing tests fixed (PERFORM UNTIL
  evaluations, sending operands of arithmetic statements, WRITE / REWRITE
  before the record is written, DEBUG-CONTENTS of 2048 characters).
  DB passes with 0 failures.
- [x] **1.3 Communication (CM module): not supported in this release.**
  The COMMUNICATION SECTION, SEND, RECEIVE, ENABLE, DISABLE, PURGE and
  ACCEPT MESSAGE COUNT get a clear error (`tests/diag/communication`).
  To be stated in the release notes (4.5).
- [x] **1.4 Subset flagging (FIPS).** `--subset=minimum|intermediate`
  reports the elements outside the subset ("NON-CONFORMING STANDARD",
  `-Wsubset`). The NIST flagging programs score every message they expect
  (`tools/nist/flags.py`); `tests/diag/subset-*`.
- [x] **1.5 Reference format in the DATA DIVISION.** `-Warea` for division
  and section headers, FD / SD / RD, level 01 and 77 entries and
  DECLARATIVES outside Area A (`tests/diag/area`).
- [ ] **1.6 Exclusions written down.** IX110A (invalid PICTURE with P,
  rejected by GnuCOBOL too) and ST301M (corrupt in the suite file).
  Done when: listed with the reason in the release notes.
- [ ] **1.7 Release claim.** A table of the NIST modules: programs, tests
  passed / failed / deleted, exclusions.
  Done when: generated by a script from `tools/nist/run.sh` output and
  included in the release notes.

## 2. Platforms

- [x] **2.1 Windows runtime layer.** `runtime/x86_64/windows/os.asm`: the OS
  contract on kernel32 (console, files, time, memory, environment, exit).
- [x] **2.2 Calling convention.** Generated code and the arch layer keep the
  System V convention on Windows (it is internal to the program); the OS
  layer converts to Win64 at the kernel32 boundary (shadow space, argument
  registers, stack alignment), and the entry point realigns the stack
  (`runtime/ABI.md` section 1). Calling C code or being called from it
  (Win64) is for later.
- [x] **2.3 PE output.** The built-in linker writes PE32+ executables with
  an import table (`docs/linker.md`); `cobalt hello.cbl` gives `hello.exe`
  with no other tool. The assembler gained `%macro`. Objects (`-c`) stay
  ELF, which cobalt links for either system; COFF objects for other linkers
  are for later.
- [x] **2.4 cobalt builds for Windows:** `make windows` cross-builds
  `bin/cobalt.exe` with MinGW-w64 (the runtimes are embedded as C, see
  `cobalt embed`). A native build on Windows (MSYS2) is untested.
- [x] **2.5 Windows sources.** CR LF sources and copybooks, `\` and drive
  letters in COPY paths, COBCPY with `;`; carriage returns dropped from the
  standard input.
- [x] **2.6 Cross-checks.** The test programs (`make test-windows`), the
  run-time error tests and the NIST suite give the same results as on Linux
  (run on Windows through WSL). CI (5.1) still to come.

## 3. Runtime

- [x] **3.1 Run-time checks** (`-fcheck`): subscripts and their OCCURS
  (and the current OCCURS DEPENDING ON value), OCCURS DEPENDING ON values,
  reference modification start, length and end. A failed check stops the
  run with the source line, the program and the value
  (`tests/runerr`, `runtime/ABI.md` section 15).
- [ ] **3.1b Numeric data check** (`-fcheck`): a numeric DISPLAY or
  PACKED-DECIMAL item that does not hold a valid number where it is used.
- [x] **3.2 Run-time error messages.** Every runtime stop (missing program
  on CALL, file errors without handling, checks) reports the program and
  the source line, with a nonzero exit status.
  Done when: documented and tested.
- [x] **3.3 Exit status.** STOP RUN exits with RETURN-CODE (an extension,
  shared by the programs of the run unit); documented.
- [ ] **3.4 File assignment.** ASSIGN names mapped through environment
  variables and a search path (for example `DD_name`, `dd_name`, `name`,
  and `COB_FILE_PATH` as GnuCOBOL does, or cobalt's own documented scheme).
  Done when: documented and tested.
- [ ] **3.5 Limits documented.** In-memory SORT / MERGE, indexes built at
  OPEN, the largest record and file sizes.
  Done when: in the user guide (4.3); larger-than-memory sorting is a
  known limitation, not a release blocker.

## 4. Documentation

- [x] **4.1 LICENSE** (MIT).
- [x] **4.2 README.** What cobalt is, status (alpha, COBOL-85), supported
  platforms, install, a first program, links to the docs, license.
- [x] **4.3 User guide** (`docs/guide/`):
  - [x] getting started (install, compile, run, several sources, CALL)
  - [x] command-line reference (every option, generated from or checked
    against `--help`)
  - [x] language support: what of COBOL-85 is implemented, module by
    module, and what is not
  - [x] strictness and dialects (`-X`, `-D`, `-f`): the extensions each
    level accepts
  - [x] diagnostics and warnings
  - [x] files: organizations, ASSIGN, status codes, the record and index
    formats on disk
  - [x] runtime: environment variables (COB_SWITCH_n, COB_SET_DEBUG,
    no file mapping in this release), exit status, error messages
  - [x] known limitations
- [ ] **4.4 Developer docs** reviewed: build from source on Linux and
  Windows, architecture overview (lexer, preprocessor, parser, IR, backend,
  assembler, linker, runtime), `runtime/ABI.md`, `docs/assembler.md`,
  `docs/linker.md`, how to run the tests and NIST.
- [ ] **4.5 Release notes / CHANGELOG** for 0.1.0-alpha: highlights, NIST
  table (1.7), known limitations, exclusions.
- [ ] **4.6 Examples** (`examples/`): a few complete programs (files,
  SORT, CALL, copybooks), built by CI.

## 5. Quality

- [ ] **5.1 CI** on Linux and Windows: build, `make test` (programs and
  diagnostics), NIST, on every push.
- [ ] **5.2 No crashes on bad input.** Fuzz the compiler with mutated NIST
  sources and the test programs.
  Done when: no crash, hang or assertion in an agreed run (for example one
  hour), every finding fixed with a test.
- [ ] **5.3 Syntax errors keep the later checks running** where the syntax
  tree is sound (now only undefined names do).
- [ ] **5.4 Benchmarks** recorded for the release: compile time
  (`tools/bench/compile.py`) and run time against GnuCOBOL.
- [ ] **5.5 Compiler warnings clean.** cobalt builds with `-Wall -Wextra`
  without warnings, with gcc and clang, release build with `-O2`.

## 6. Command line

- [x] **6.1 `--version`** (version, target, build date).
- [x] **6.2 Options without effect** hidden or rejected: `-S COBOL-2002`,
  `-S COBOL-2014`, `-E cobalt-basic`.
- [x] **6.3 Unknown options** named in the error (an unknown long option
  now prints `Unknown option -`), with a "did you mean".
- [x] **6.4 `--help` accurate:** `-i` is not required (sources may be
  arguments), every option listed once.
- [x] **6.5 Exit status** of the compiler documented (0 success, 1 errors).

## 7. Packaging and release

- [ ] **7.1 Version number** in one place (`0.1.0-alpha`, `include/version.h`),
  shown by `--version` and in the release notes.
- [ ] **7.2 `make install`** (PREFIX, DESTDIR): the `cobalt` binary, man
  page or docs, a copybook directory searched by default.
- [ ] **7.3 Release builds:** `cobalt-0.1.0-alpha-linux-x86_64.tar.gz`
  (static binary) and `cobalt-0.1.0-alpha-windows-x86_64.zip`, each with
  README, LICENSE and the release notes; checksums.
- [ ] **7.4 Smoke test** of each release build on a clean machine: unpack,
  compile and run the examples.
- [ ] **7.5 Tag** `v0.1.0-alpha`, GitHub release with the builds and notes.

## Can wait for beta

- Debug information (DWARF line numbers) for stepping through COBOL source
  in gdb.
- Compiler listing: source with line numbers, cross-reference, data map.
- Dynamic CALL of separately compiled modules, and calling C (and being
  called from C), documented.
- Larger-than-memory SORT; disk-based indexes.
- COMP-1 / COMP-2 (an extension).
- A man page.
- COMP-5 DISPLAY width matching GnuCOBOL.
